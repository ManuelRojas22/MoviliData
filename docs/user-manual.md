# Manual de Usuario

## Ingreso

Abra `/users/login/` y use:

```text
admin / admin123
```

## Dashboard

Permite monitorear metricas de congestion, alertas, mapa operativo y graficas.

## Trafico

Muestra zonas con congestion, velocidad promedio y estado operativo.

## Rutas

Lista rutas recomendadas con menor riesgo y visualizacion en mapa.

## Predicciones

Use el control de hora para estimar la congestion esperada por zona.

## Zonas de Riesgo

Muestra heatmaps y marcadores con niveles de riesgo.

## Alertas

Centraliza eventos preventivos para priorizar respuesta urbana.
